# Prototype lesson

`rag-vs-finetuning.json` is the first lesson, built to prove the pipeline end to end (lesson JSON → Sarvam voice → Remotion → web). It predates the KTU syllabus plan, so it has no `topicId`, `example` or `review`, and it doesn't validate against the current lesson schema.

It is kept here as a reference for narration style and animated diagrams. Its rendered video stays published until `npm run index` is next run, which rebuilds the catalogue from `lessons/` only.
